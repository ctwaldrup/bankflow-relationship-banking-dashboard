# BankFlow — Relationship Banking Dashboard

BankFlow is a front-end portfolio project that explores how software can support relationship bankers with customer follow-up, service-case management, needs-based conversations, and simplified funds-availability education.

The application uses **fictional customers and demo balances only**. It does not contain real customer data, proprietary bank information, or production banking logic.

## Why this project exists

Banking work is highly operational: bankers manage customer relationships, resolve service issues, explain account processes, document next steps, identify financial needs, and coordinate escalations. BankFlow turns those real-world workflow patterns into a software project.

The goal is to demonstrate the intersection of:

- Banking domain knowledge
- Customer relationship management
- Operational problem solving
- Front-end software development
- Data-driven workflow design

## Features

- Relationship portfolio dashboard
- Fictional customer profiles and product relationships
- Needs-based relationship opportunities
- Follow-up scheduling cues
- Service-case queue with status and priority filtering
- New service-case creation workflow
- Simplified funds-availability estimator for educational use
- Product penetration and case-category analytics
- Responsive layout for desktop and mobile

## Tech stack

- HTML5
- CSS3
- Vanilla JavaScript
- Browser-native dialog and form APIs

## Banking concepts represented

BankFlow models general banking workflows such as relationship reviews, account servicing, card disputes, transfer issues, access problems, customer follow-up, documentation, escalation, and funds-availability conversations.

The funds-availability section is intentionally simplified and should **not** be treated as legal, compliance, or Reg CC advice. Real financial institutions must follow their own policies, disclosures, procedures, and applicable law.

## Run locally

No build step is required.

1. Download or clone the repository.
2. Open `index.html` in a modern browser.
3. Use the navigation to explore the dashboard, client portfolio, service cases, funds-availability demo, and analytics.
